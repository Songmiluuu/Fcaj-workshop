# Self-Assessment

During my internship from **June 1 to August 15, 2026**, I participated in the
development of **EduCloud**, a cloud-based learning platform. My assigned work
focused on Enrollment, Progress, Upload, API testing, and application-log
verification.

The project gave me practical experience with FastAPI, SQLAlchemy, PostgreSQL,
Amazon Cognito, Amazon S3, CloudWatch, Postman, and the integration between the
backend and frontend. It also improved my ability to turn requirements into API
rules, test both successful and failed flows, debug integration issues, and
document a technical solution clearly.

I assessed the internship against twelve professional and technical criteria.

## Areas for improvement

- Communicate progress, blockers, and interface changes with the team more
  regularly instead of relying mainly on technical documentation.
- Plan screenshots, test results, and report assets earlier so the final phase
  can focus on review rather than evidence collection.
- Expand end-to-end testing for authentication, enrollment, progress, upload,
  and media delivery.
- Improve operational readiness with clearer alarms, log retention, backup,
  cost monitoring, and repeatable infrastructure configuration.

## Overall evaluation

I assess my internship performance as **Good**. I completed the main technical
scope assigned to me, strengthened the work through automated and API-level
testing, and documented the solution in a structured bilingual report. My
strongest progress was in backend reliability and problem solving. The main
area I want to improve is maintaining more frequent team communication and
organising final validation materials earlier.
